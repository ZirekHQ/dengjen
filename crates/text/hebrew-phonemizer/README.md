# Hebrew phonemizer

Hebrew grapheme-to-phoneme conversion (diacritization + IPA) for the dengjen-tts speech synthesis engine.

Diacritizes undotted text with the Nakdimon ONNX model, skipping text that already carries niqqud, then converts the diacritized form to IPA.

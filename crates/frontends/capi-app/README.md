# libdengjen-app

C API over [`dengjen-app`](../../app) for the Windows app (P/Invoke) and any other shell that cannot link Rust directly. `libdengjen_app.h` is generated by `build.rs`.

- `libdengjenAppSentences` returns the sentences of a UTF-8 string, each with its UTF-8 byte and UTF-16 code-unit range; free the array with `libdengjenAppFreeSentences`.
- `libdengjenAppTextFromFile` reads a `.txt`, `.md` or `.html` file and returns its plain text; free it with `libdengjenAppFreeString`.

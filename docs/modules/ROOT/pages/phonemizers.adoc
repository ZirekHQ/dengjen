= Phonemizer language coverage

dengjen-tts phonemizes text through three dedicated crates under `crates/text/`
(`dengjen-espeak-phonemizer`, `dengjen-hebrew-phonemizer`, `dengjen-pinyin-phonemizer`) that
Piper, Kokoro, and MeloTTS each call directly rather than through a shared `Phonemizer` trait
(see xref:architecture.adoc[Architecture] for why). Language support is therefore a property of
*which phonemizer a voice manifest selects*, not a single project-wide language list.

== What's actually wired up today

[cols="1,2,3"]
|===
|Backend |Phonemizer |Language coverage

|Piper
|`phoneme_type: "espeak"` (default)
|Whatever espeak-ng voice the manifest's `espeak.voice` field names — see the full list below.

|Piper
|`phoneme_type: "text"`
|None — raw passthrough, for voices already trained on phonemic/symbol text.

|Piper
|`phoneme_type: "hebrew"`
|Hebrew only (Nakdimon diacritization + IPA; needs the `hebrew` Cargo feature).

|Piper
|`phoneme_type: "pinyin"`
|Mandarin Chinese only.

|Kokoro
|Derived from the selected voice's name prefix, not manifest-configurable
|`en-US`, `en-GB`, Japanese, Mandarin, Spanish, French, Hindi, Italian or Brazilian Portuguese.

|MeloTTS
|`{"type": "espeak", "voice": "..."}`
|English, Spanish, French, Japanese, Korean.

|MeloTTS
|`{"type": "pinyin", "model_dir": "..."}`
|Mandarin Chinese, with real tone extraction (needs the `pinyin` Cargo feature).
|===

MeloTTS's pinyin path and Piper's `hebrew`/`pinyin` paths are the only ones with dedicated,
tone- or diacritic-aware handling; espeak-backed paths get IPA phonemes only.

[IMPORTANT]
====
This is espeak-ng's own capability, not a dengjen-tts guarantee. dengjen-tts's own test suite
only exercises English voices end-to-end; any other language on this list will phonemize (espeak-ng
supports it), but whether a *given Piper or MeloTTS ONNX voice* — trained on some specific
language's phoneme set — actually produces intelligible speech from that phonemization is
untested by this project and depends entirely on the voice model itself.
====
